# Cursor Models — Rules

Confirmed patterns to apply by default when choosing or recommending Fable 5 / GPT-5.6 Sol.

1. **Pick by failure mode, not brand.** Use Fable 5 when the bottleneck is repo-level correctness, long-horizon autonomy with self-checks, or vision/document-heavy knowledge work. Use Sol when the bottleneck is terminal/tool-agent throughput, token efficiency, concise planning, or max/ultra-style parallel subagent decomposition.
2. **Do not recommend Fable for offensive cyber or advanced bio.** Classifiers fall back to Opus; Mythos 5 is the restricted path for those domains.
3. **Treat "unique use cases" as capability ceilings.** In Cursor, tool access is shared; uniqueness is finishing work other models abandon, get wrong, or cannot afford.
4. **Budget awareness.** Fable is ~2× Opus and draws from Other Models; Sol is cheaper than Fable but still flagship-priced vs Terra/Luna — reserve for hardest work.
5. **Privacy gate for Fable.** Teams/Enterprise with Privacy Mode need explicit data-retention approval before Fable is usable.
