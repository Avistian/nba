# Dataset & Evaluation — Knowledge

Facts and patterns about datasets (`dataset_mode`) and the experiment leaderboard (Phase 17).

## Datasets behind one flag

`Settings.dataset_mode ∈ {"flat", "relational"}` (default `"flat"`) selects the simulator:

| Mode | Module | Logs | Sidecars |
|------|--------|------|----------|
| `flat` | `data/simulator.py` (untouched) | `data/logs.parquet` | — |
| `relational` | `data/relational_simulator.py` (mirror) | `data/relational/logs.parquet` (+ optional `household_id` col) | `households.parquet`, `edges.parquet`, `graph.npz` |

Both emit the **same** `BanditEvent` schema, so every learner consumes either without change.

## Relational world structure

`RelationalWorld` (households, `near`/competitor edges, per-door interaction histories) layers four
graph-dependent effects on top of the flat latent score: **neighbor social proof**, **household
momentum**, **temporal history fatigue**, **competitor overlap**. A degenerate world (no edges/history)
collapses to the flat oracle. Generated by `scripts/generate_relational_logs.py`.

## Graph builder

`data/graph.py::build_graph(world)` → typed `HeteroGraph` (numpy, no torch) for the future RDL model.
Node features come from a graph allow-list mirroring `features.ALLOWED_FEATURES`; `save_graph`/
`load_graph` round-trip via `npz`.

## Grading oracle facade

`eval/oracle.py`: `Oracle` Protocol + `FlatOracle` (pass-through) + `RelationalOracle` (binds a
`RelationalWorld`), chosen by `oracle_for(settings, world=...)`. `run_demo.py` and the leaderboard reach
ground truth only here. When the demo repositions doors onto a dense block in relational mode, it
rebuilds the world's `near_edges` via `world_from_contexts` so the oracle stays consistent.

## Leaderboard mechanics

- `eval/metrics.py::evaluate(settings, n_shifts, seeds, ...)` reuses `run_demo` across seeds/shifts and
  aggregates `ExperimentMetrics` (realized shift value mean/std/cvar, decision regret, OPE value/lcb,
  route time).
- `eval/leaderboard.py::record_experiment(...)` appends an `ExperimentRecord` to `leaderboard.jsonl`
  with sign-normalized deltas vs baseline, the DR-gate result (`ope/gate.py`), git rev, and a
  lift/regression/neutral verdict. `render_table` prints the board best-first.
- `scripts/run_experiment.py --baseline-only` records the reference row; `--experiment-id ... --phase
  ... [--dataset relational] [--set NBA_KEY=value ...]` grades a config and refreshes
  `artifacts/leaderboard.md`.

## Notebooks

The 9 parametrized notebooks resolve dataset paths/model/oracle from a top-level
`DATASET_MODE = "flat" | "relational"` cell; originals live unchanged in `notebooks/old/`.
